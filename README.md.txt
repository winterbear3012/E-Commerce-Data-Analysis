# Olist E-Commerce Data Analysis

## Project Overview

This project analyzes the Olist Brazilian E-Commerce dataset to understand sales performance, customer behavior, payments, reviews, and delivery performance.

## Tools & Technologies

- Python
- Pandas
- PostgreSQL
- SQL
- Power BI
- Git & GitHub

## Project Structure

- `data/` — dataset files
- `src/` — Python analysis and data-processing scripts
- `SQL/` — database creation and analysis queries
- `reports/` — project insights
- `Olist E-Commerce.pbix` — Power BI dashboard

## Key Analysis

- Total orders and revenue
- Average order value
- Monthly revenue trends
- Revenue by product category
- Revenue by payment method
- Customer review scores
- Delivery time
- Freight costs
- Revenue by customer location

## Dashboard

The Power BI dashboard provides an interactive overview of the main e-commerce performance metrics and trends.

## Dataset

Olist Brazilian E-Commerce Dataset from Kaggle.
